# 《喜鹊教搭窝》文本审读
JEF-008，3–6 岁亲子共读试稿。独立作品页加 25 页正文。

[英文底稿](01_英文底稿.txt) · [独立全译](02_独立全译.txt) · [绘本讲述稿](03_绘本讲述稿_R2.md)

英文选 Joseph Jacobs 编述的 English Fairy Tales（1890）中 The Magpie’s Nest，页 204–206。原书以打油诗开场，织窝示范中有五只鸟先后离开，留下的斑鸠并未听课。全译保留歌谣、鸟名和三次叫声。Taffy 是叫声拟成人话时的称呼，绘本只取“两根”的回声，孩子可以跟读。[英文逐页转录](https://en.wikisource.org/wiki/English_Fairy_Tales/The_Magpie%27s_Nest)

**中文发行对照。** 已对读 Sparkler 公开发行的 Camp 2024 简中活动读本《喜鹊筑巢》全文，该篇未见个人译者署名。这个版本从小鸟需要安全的家讲起，孩子在喜鹊开课之前就知道为什么要学。其结尾保留斑鸠的反复叫声和喜鹊生气飞走。我们的稿子用“第一根树枝往哪儿搁”起问，先让孩子看见一个要解决的问题；在喜鹊飞走后，镜头再跟三只学生回到各自的窝。后一个场景是项目增写。纸本另查到张逸旻译《快乐王子——英国经典童话》收《喜鹊的窝》，仅核到书目，未据此判断其译法。[简中活动读本](https://playsparkler.org/wp-content/uploads/2024/07/Chinese-Stories_Camp24-1.pdf) · [纸本目录](https://search.megbook.com.tw/mall/detail.jsp?proID=2199318)

**相对 R1 的改动。** 原稿把 blackbird 写成乌鸦、跳过猫头鹰和椋鸟，结尾另设下雨。新稿恢复鸫鸟、乌鸫、猫头鹰、麻雀、椋鸟的先后次序，让每次离开都与一项看得见的动作相连。作品页以后的前两页交代所求、困难与老师；末两页分别回看泥、枝和羽毛，让孩子看懂各家为何学成不同模样。低龄版省略开场烟草歌谣。树枝弹起、麻雀追枝梢、椋鸟蹭羽毛是画面化增写。本篇按民间故事讲述。
