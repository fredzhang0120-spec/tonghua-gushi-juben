# 童话故事版本对读

每个故事保留四份可追溯的材料。英文底稿注明书、版次、篇页、译者或编述者；格林与安徒生另登记德文、丹麦文原作。项目完整中文译稿跟随所选底稿，保留关键对话、重复回合和结局。绘本版从全译重新选场，标出合并和新增的地方。中文发行参考至少核对一种实际出版译文的故事正文，登记译者、版本、查阅范围和有意义的差异。

本次清点 100 篇 R1 的正文汉字数（不含标题、标点）。最短 227 字，最长 624 字，中位数 324.5 字，92 篇少于 400 字。字数用于发现异常；场面能否成立，要逐本读。比如《六件星花衬衣》省略了哥哥为何变成天鹅、谁在宫中陷害妹妹，末尾孩子被送回却没有交代谁藏了孩子。1882 年 Lucy Crane 英译《The Six Swans》可以核查这三处。另如《第十二个人去哪儿了》，清点人数直到把自己也算上，只需一场完整的误会，补写的价值取决于孩子能否跟着数。[格林出版英译](https://www.gutenberg.org/files/19068/19068-h/19068-h)
