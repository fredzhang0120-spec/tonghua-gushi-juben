## 哪些地方值得借鉴

| 场面 | R1 怎么写 | 出版译本给出的线索 | R2 怎样处理 |
|---|---|---|---|
| 皇帝为什么花这笔钱 | 交代了他愁游行穿什么，织工随即开工。 | 神奇衣料引得皇帝想检验臣下；轮到自己可能受检验，他才改派别人先看。 | 第 5–9 页写他先盘算谁配当官，再写已经走到大厅门前的手缩了回来。推门是本次改编动作。 |
| 一个人的谎话怎样变成朝廷的一致意见 | 大臣编出两句赞美，下次看见皇帝时已在试衣。 | 老大臣一边看不见，一边记住骗子的解说；另一位官员也不肯承认；两人陪皇帝再看，前面说过的谎又逼他们指给皇帝看。 | 第 10–19 页给两位官员不同的反应。一个记词，一个主动提议游行。原版由随行人等建议游行，这里把建议移交给第二位官员。 |
| 谁先敢在街上说实话 | 有孩子、父亲、街坊的传话，值得保留。 | 群众起初借孩子之口传话，最后才公开承认自己的眼睛看到了什么。 | 第 25–30 页留出街口从夸赞到私语再到喊声的时间。 |
| 众人已经明白，故事为什么还能往下走 | 皇帝和侍从继续前进，结尾成立。 | 百姓的选择与皇帝的选择分开了。听见真话不等于他肯立刻停下来。 | 最后两页让侍从先追上皇帝，再端起两只空手。保留讽刺，不添道理或悔改。 |

英文逐段译稿与绘本是两件可单独阅读的作品。中文发行译文用于校读场次、语气、讽刺和人物关系，这里保存书目信息与独立评注。R2 的钉眼、皇帝迟迟没有推开的门、侍从小跑等是项目改编细节。
