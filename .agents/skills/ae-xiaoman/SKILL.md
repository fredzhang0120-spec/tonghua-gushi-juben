# AE 小漫制作与审校

先读[制作工艺](references/制作工艺.md)，从仓库根目录的[共享领稿表](../../../共享领稿表.md)定位作品编号、负责人和当前稿。打开表格指向的版本；同一作品的历史 R1、短样、送听包和正式包可能同时存在。

1. **确定本轮职责。** 文本窗口负责底本、独立全译、发行版本对读、文学润色和整库状态。制作窗口负责制作前复核、音图、预览与交付。只做文稿时，交付逐页稿和审读记录即可。收同事来稿时，保留原 ZIP，先查重和逐页盘点，再对有问题的书生成修订版。
2. **跨机领取。** 将共享表的编号、稿版、负责人、日期和阶段提交到 main，以远端登记成功为锁定。冲突时刷新对应行，已有归属则另选。单窗口最多五篇，首篇先听审再扩批。接手正在进行的书，先查前任留下的产物、反馈范围和待办。
3. **通读后锁稿。** 从底本列出主角愿望、行动、转折、结局，再看孩子只听逐页稿能否复述。读出前两页和最后两页。记录漏掉的因果、称谓混乱、成人化对白及改编新增，按页修改；留存所用版本或提交号。必要时补写有情节价值的场面。
4. **先用短样校准。** 选有动作、旁白和对白的连续几页，写清该听哪句、重音在哪里。提交可试听文件和对应页码。把听审结论分别记到音色、语气、停连或音效；保留已采用片段。返修局部时同时回听衔接的前后句，全书节奏有问题时回查源音、后加停顿与翻页留白。
5. **出整本与复核。** 依工艺说明完成图文、逐页音频和可翻页预览。机器查对应关系、字数、尺寸、时间和响度；人工通听语气、误读、转场、角色对白及尾声，缩到设备尺寸看图。问题写为“作品／版本／页码或时间点／现象／改后如何判断”，方便另一位同事直接复听。
6. **包内复验并回填。** 从实际导出包重新验证；登记技术核验、人工听审、正式出包、后台导入和真机测试各自的结果。待审样本与正式交付分开存放。用同一作品行回填版本和状态；若产物存放在共享文件区，登记同事有权限打开的地址。交接注明下一位负责人要做的具体动作。
