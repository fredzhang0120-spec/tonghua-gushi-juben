# 《皇帝的新装》正式成品样例

本书采用已确认的自然节奏版，7–10 岁，作品页加 32 页正文，整篇 6 分 07 秒。连续解码实测 −13.06 LUFS，最高真峰值 −1.00 dBTP。响度基准来自《北风和太阳》R4。

1. [先听作品页到正文第 2 页](作品页至正文第2页_交付音量试听.wav)。约 25 秒，由正式包的 001–003.mp3 连续解码为 WAV，保留交付音量。听完整书名如何落下，再听侍从开口时旁白和对白如何接上。
2. [对照完整逐页文本](../../版本对读/HCA-001_皇帝的新装/自然节奏定稿_逐页文本.md)。先看前两页怎样交代皇帝爱换衣，再看最后一页怎样用托衣摆的动作收尾。
3. [下载 AE11／AE30 正式交付 ZIP](皇帝的新装_自然节奏定稿_双端合并.zip)。解压后直接进入作品编码目录，检查双端封面、同页图图音、真实章节标题和连续页码。想听全书时按 001 至 033 顺序播放。
   
ZIP 共 103 个文件，SHA-256 为 `a146a992aa2e174d88d5a087c7fd35d0d2bc8fe240f778e02e2c86e25cb63667`。样例用途为本项目制作交接和内部对照。
